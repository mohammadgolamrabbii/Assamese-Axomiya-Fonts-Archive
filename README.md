Sovereign Assamese typography archive celebrating the Brahmaputra Valley literary heritage with full support for unique Axomiya glyphs (Rô ৰ and Wô ৱ).

## ⚡ Fast Installation

### Linux & macOS (Bash)
```bash
curl -fsSL https://raw.githubusercontent.com/Open-Typography-Foundation/Assamese-Axomiya-Fonts-Archive/main/install.sh | bash
```

### Windows (PowerShell)
```powershell
irm https://raw.githubusercontent.com/Open-Typography-Foundation/Assamese-Axomiya-Fonts-Archive/main/install.ps1 | iex
```
